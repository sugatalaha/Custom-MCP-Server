# Custom-MCP Server
[![M8ven Score](https://m8ven.ai/badge/mcp/sugatalaha-custom-mcp-server-bnsdrt?v=0d4b0cb15f91680651f11582f3c30f06)](https://m8ven.ai/mcp/sugatalaha-custom-mcp-server-bnsdrt?s=readme)

This is a Custom MCP Server which can be configured to understand legacy or propietory codebase. The main objective behind the project is to ensure the integration of local LLM agents with this MCP server so that they can be exposed to the tools provided instead of searching through the codebase randomly on user queries.
